# Granjas Diversión

Landing estática en HTML, CSS y JavaScript, sin dependencias.

## Abrir
Descomprime el ZIP y abre dist/index.html en tu navegador.
Para publicarla en hosting, sube el contenido de dist a la carpeta pública.

## Editar
- dist/index.html: textos y estructura.
- dist/styles.css: diseño y adaptación a celular.
- dist/app.js: interacciones, formularios y avisos.
- dist/assets/: fotografías utilizadas.
- make.py: generador opcional del HTML. Ejecutarlo sobrescribe dist/index.html.

## Pendientes para producción
Incorporar logo oficial, fotografías del Parque Acuático, video, ubicación, WhatsApp, Facebook, aviso de privacidad y reglamento.
Los formularios validan campos, pero no envían ni almacenan datos. Es necesario conectar el destino de los registros.
